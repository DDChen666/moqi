# 在 Mac 上安裝默契

大約 10 分鐘，其中大半是等辨識模型下載。

## 先看一下

- **需要**：
  - Apple 晶片的 Mac（M1 以後）。
  - macOS 15 以後。
  - 約 2 GB 空間放辨識模型。
- **目前只在** macOS 26、M3 16 GB 上完整測試過。
- **為什麼第一次打開要多幾步**：
  - 默契是免費的開源軟體，沒有付費加入 Apple 的開發者計畫，所以 macOS 認不得它的簽章，第一次打開時會擋下來。
  - 這是 macOS 對所有沒有 Apple 簽章的 App 的做法，不代表軟體有問題。原始碼全部公開在這個頁面，可以自己檢查，也可以自己編譯。
  - 這個步驟只需要做一次。

## 1. 下載，放進「應用程式」

1. 到本頁的 [Releases](../../../releases) 下載最新的 `Moqi_x.y.z_aarch64.dmg`。
2. 打開下載好的檔案，會出現一個視窗。
3. 把裡面的「默契」圖示拖到旁邊的「應用程式」資料夾。
4. 退出這個 dmg（在 Finder 側邊欄按旁邊的 ⏏）。

> 一定要放進「應用程式」再打開。直接從 dmg 裡打開，之後的權限設定會出問題。

## 2. 第一次打開

1. 打開「應用程式」資料夾，雙擊「默契」。
2. macOS 會跳出「**未打開「默契」**」（較舊的 macOS 寫「無法打開「默契」」），說 Apple 無法驗證它是否為惡意軟體。按「**完成**」，不要按「丟到垃圾桶」。
3. 打開「**系統設定**」（螢幕左上角 →「系統設定⋯」）。
4. 左邊點「**隱私權與安全性**」，右邊一直捲到最下面的「安全性」。
5. 會看到一行「已阻擋『默契』以保護你的 Mac」，按旁邊的「**強制打開**」（英文介面是 Open Anyway）。
   - 這個按鈕只在剛被擋下的一小時內出現。沒看到的話，回到第 1 步再雙擊一次。
6. 再跳出確認視窗時按「**強制打開**」，然後輸入 Mac 的登入密碼（或按 Touch ID）。
7. 默契就會打開。之後直接雙擊就好，不會再問。

### 如果出現「「默契」已損毀，無法打開」

有些情況 macOS 會說它「已損毀」，而且系統設定裡不會出現「強制打開」。檔案並沒有壞，是 macOS 替下載的檔案加了一個「來自網路」的標記。拿掉這個標記就好：

1. 打開「**終端機**」：按 ⌘ 空白鍵，輸入「終端機」，按 Return。
2. 複製下面這一行，貼進終端機，按 Return：

   ```
   xattr -dr com.apple.quarantine /Applications/Moqi.app
   ```

   沒有任何訊息就是成功了。

3. 關掉終端機，回到「應用程式」雙擊「默契」。如果又被擋，照上面第 2 步之後的做法按「強制打開」。

## 3. 第一次開啟的三步

默契打開後會帶你完成三步：

1. **權限和辨識模型**
   - **麥克風**：跳出詢問時按「允許」。
   - **輔助使用**：默契要靠這個權限，才能在你按快捷鍵時聽得到，並把字貼進其他 App。
     - 按畫面上的按鈕會打開「系統設定」→「隱私權與安全性」→「輔助使用」。
     - 在清單裡把「默契」的開關打開，可能要輸入密碼。
     - 清單裡沒有「默契」的話，按下方的「+」，到「應用程式」選「默契」。
   - **辨識模型**（約 1.5 GB）這時已經在背景下載，視網路速度要幾分鐘。
2. **選「原話」或「整理」**：
   - 原話：完全在這台電腦上處理，不需要任何帳號。
   - 整理：會把辨識出的文字送去整理。要貼 API key，也可以先略過，之後在設定裡再填。
3. **試說一句**：按住右邊的 ⌥ Option，說一句話，放開。看到字出現就完成了。

完成後，默契會待在螢幕右上方的選單列（一個聲波圖示）。關掉視窗不會結束它，平常也不用打開視窗。

## 之後怎麼更新

1. 在選單列按默契的圖示 →「結束」。
2. 下載新版的 dmg，照第 1 節把「默契」拖進「應用程式」，選「取代」。
3. 打開新版。通常不需要重新給權限；如果快捷鍵沒反應，看下面「按快捷鍵沒反應」。

## 移除

1. 在選單列按默契的圖示 →「結束」。
2. 把「應用程式」裡的「默契」拖到垃圾桶。
3. 想連資料一起刪（歷史紀錄、錄音、設定）：
   - 在 Finder 按 ⇧⌘G，貼上 `~/Library/Application Support/tw.yuyin.dictation`，按 Return，把這個資料夾丟到垃圾桶。
4. 辨識模型（約 1.5 GB）另外放在 Hugging Face 的共用資料夾：
   - 在 Finder 按 ⇧⌘G，貼上 `~/.cache/huggingface/hub`，按 Return，把 `models--handy-computer--Qwen3-ASR-1.7B-gguf` 丟到垃圾桶。
   - 同一個資料夾裡的其他項目屬於其他軟體，不要動。
5. 有填過 API key 的話，key 存在「鑰匙圈存取」裡。搜尋「tw.yuyin.dictation」就找得到，可以刪掉。
6. 「系統設定」→「隱私權與安全性」→「輔助使用」和「麥克風」裡的「默契」，可以選起來按「−」移除。

## 常見問題

**按快捷鍵沒反應**

- 先確認選單列有默契的圖示（沒有的話，到「應用程式」打開它）。
- 到「系統設定」→「隱私權與安全性」→「輔助使用」，確認「默契」的開關是打開的。
- 開關明明是開的卻沒反應（常發生在更新之後）：把「默契」選起來按「−」刪掉，再按「+」重新加回來，然後在選單列結束默契、重新打開。
- 還是不行：打開「終端機」貼上下面這行，再重新打開默契、重新給權限：

  ```
  tccutil reset Accessibility tw.yuyin.dictation
  ```

**說話了但沒有字**

- 「系統設定」→「隱私權與安全性」→「麥克風」，確認「默契」是打開的。
- 在默契的「設定」裡確認選對了麥克風。
- 剛裝好時辨識模型可能還在下載（第一次開啟的第 1 步看得到進度），等下載完成再試。

**字貼到別的地方了**

- 按下快捷鍵之後換了視窗，默契不會亂貼，而是複製起來，膠囊會顯示「已複製，請自己貼上」。在要的地方按 ⌘V 就好。
- 也可以在選單列按默契的圖示 →「貼上上一次」。

**在 App 列表或 Spotlight 找不到**

- 中文介面下它叫「**默契**」，英文介面下叫「Moqi」。
- 確認它在「應用程式」資料夾裡，不是還在 dmg 或「下載項目」裡。

**有沒有把我的聲音傳出去？**

- 沒有。辨識全程在這台電腦上完成。
- 選「整理」或「潤飾」時，送出去的只有辨識出的文字和你字典裡的詞。
- 每一次送出了什麼，都可以在「歷史紀錄」點開那一筆查看。
