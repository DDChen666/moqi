# 默契 Moqi

**讓默契幫你打字。** 中英夾雜，一聽就懂。

按住右邊的 Option 說話，放開，字就出現在你正在打字的地方。聲音在你的電腦上辨識，不會上傳。要不要再把文字交給 AI 整理，由你決定。

## 跟其他語音輸入哪裡不一樣

- **聽得懂中英夾雜。** 「幫我把這個 PR 的 description 改短一點」這種句子，英文會照原樣留下，不會被翻成中文，也不會整句變成英文。選模型之前，先用 30 段真人錄音比較了 8 個能在電腦上跑的辨識模型，以「意思有沒有聽錯」評分，最後選了 Qwen3-ASR 1.7B。
- **看場合整理。** 同一句話，在 LINE 裡會像聊天：句尾不加句號，也不會換行誤送出。在 Claude Code、終端機裡，一個細節都不刪，指令和檔名照原樣。在備忘錄裡會精簡成條列。
- **聲音不出電腦。** 辨識全程在本機。選「整理」時，送去潤稿服務的只有三樣：辨識好的文字、你字典裡的詞，以及場合類別（例如「聊天」）。App 名稱、視窗標題不會送出。首頁的隱私卡會列出累計送出了多少字、送到哪裡。
- **邊說邊轉。** 你停頓的時候，默契就先把前面那段轉好。說了一分鐘再放開，也只要等最後幾秒的辨識。
- **不丟稿。** 網路斷了、潤稿失敗，就貼上沒整理的原文。辨識失敗的錄音會留在歷史紀錄裡，可以重新辨識。
- **不打擾。** 懸浮的膠囊不會搶走游標。貼上後會還原你原本的剪貼簿，也不會留在剪貼簿管理工具的紀錄裡。說到一半換了視窗，就不硬貼，改成複製。

## 下載與安裝

**需要：** Apple 晶片的 Mac（M1 以後），約 2 GB 空間放辨識模型。目前只在 macOS 26、M3 16 GB 上測試過。

1. 從 [Releases](../../releases) 下載 `Moqi_1.0.0_aarch64.dmg`，打開後把「Moqi」拖進「應用程式」。
2. 第一次打開時，macOS 會擋下來。默契沒有加入 Apple 的付費開發者計畫，所以沒有 Apple 的簽章，這是正常的。
   - 在跳出來的視窗按「完成」。
   - 打開「系統設定」→「隱私權與安全性」，捲到最下面，在「默契」那一行按「強制打開」，再輸入密碼。
   - 之後就能正常打開，不會再問。
   - 一步一步的說明、出現「已損毀」時怎麼辦、更新和移除：[docs/安裝教學-Mac.md](docs/安裝教學-Mac.md)
3. 依畫面指示完成三步：
   1. 允許麥克風與輔助使用。辨識模型（約 1.5 GB）同時在背景下載。
   2. 選「原話」或「整理」。
   3. 當場試說一句。

> 習慣用終端機的話，也可以用這行代替第 2 步：`xattr -dr com.apple.quarantine /Applications/Moqi.app`

平常默契待在螢幕上方的選單列，關掉視窗不會結束。

## 怎麼用

| 動作                 | 按鍵                              |
| -------------------- | --------------------------------- |
| 說話                 | 按住右 ⌥ Option，說完放開         |
| 免持（長段）         | 快按兩下右 ⌥ Option，說完再按一下 |
| 取消這次             | Esc                               |
| 貼錯地方、想再貼一次 | 選單列的默契圖示 →「貼上上一次」  |

快捷鍵可以在「設定」裡換。按不到 0.3 秒不會觸發，不怕誤觸。

## 整理文字（可以不用）

| 程度 | 做什麼                                                                   | 需要                     |
| ---- | ------------------------------------------------------------------------ | ------------------------ |
| 原話 | 只加標點，其他照你說的                                                   | 不需要任何帳號，全程本機 |
| 整理 | 去掉「嗯、那個」，說錯改口的只留最後的說法，口頭列點變清單。不換你的用詞 | 潤稿服務的 API key       |
| 潤飾 | 重組句子，讀起來像寫的，不像說的。適合寫信、寫文件                       | 同上                     |

- 預設的潤稿服務是 DeepSeek，也可以換成任何相容 OpenAI 格式的服務，或選「不使用」。
- API key 存在 Mac 的鑰匙圈，不會寫進任何檔案。
- 常被聽錯的名字、術語可以加進「字典」，整理時會照你的寫法。

## 隱私

| 資料                   | 放在哪裡                                                                     |
| ---------------------- | ---------------------------------------------------------------------------- |
| 你的聲音               | 只在這台電腦。最近 100 次的錄音留在歷史紀錄，可以隨時刪除                    |
| 辨識出來的文字         | 只在這台電腦。選「整理」或「潤飾」時，這段文字會送到你選的潤稿服務           |
| 用了哪個 App           | 只在這台電腦，用來判斷場合，不會送出                                         |
| 你的字典               | 只在這台電腦。選「整理」或「潤飾」時，會跟文字一起送出，讓潤稿服務照你的寫法 |
| 使用統計（首頁的數字） | 只在這台電腦，只記時間和字數，不記內容                                       |

默契沒有帳號、沒有分析追蹤，也不會自動更新。

## 從原始碼編譯

需要 Rust、Bun 和 Xcode 命令列工具，詳細步驟見 [BUILD.md](BUILD.md)。

```sh
bun install
bun run tauri build --bundles app
```

macOS 的「輔助使用」權限跟著簽章走。每次重新編譯都用同一個簽章（例如自己建的憑證，透過 `APPLE_SIGNING_IDENTITY` 指定），權限就不用重給。
